# 발행 전 체크리스트 (저장하고 싶은 글인가?)

Reviewer는 `draft.md`를 `final.md`로 넘기기 전에 아래 항목을 전부 확인한다.
하나라도 실패하면 해당 부분을 수정한 뒤 다시 처음부터 점검한다.
통과 여부는 `final.md` 맨 아래에 `## 리뷰 체크리스트` 섹션으로 기록한다.

- [ ] 첫 문장을 읽고 다음 문장이 궁금한가? (후킹)
- [ ] 제목만 보고도 클릭하고 싶은가?
- [ ] 각 섹션에 "그래서 나는 뭘 하면 되지?"에 대한 답이 있는가? (실행 가능한 인사이트)
- [ ] 빼도 뜻이 안 변하는 문장이 있는가? → 있으면 삭제
- [ ] `tone.md` 기준 어미 밸런스를 지켰는가?
- [ ] `readability.md` 기준 문장/문단 길이를 지켰는가?
- [ ] `forbidden-phrases.txt`에 걸리는 표현이 없는가?
- [ ] 이 글을 내가 북마크하거나 남에게 공유하고 싶은가? (최종 판단)

마지막 항목에 "예"라고 답할 수 없다면 발행하지 않는다. Writer 단계로 되돌려서 다시 쓴다.
